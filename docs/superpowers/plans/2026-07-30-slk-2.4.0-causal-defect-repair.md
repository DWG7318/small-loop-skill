# SLK 2.4.0 Causal Defect Repair Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add causal, fail-closed defect repair discipline to one bounded strictly serial SLK Run without adding roles, visible conversations, D-levels, or external-method lifecycle logic.

**Architecture:** Extend the existing control kernel and D0/D1 Receipt Envelopes with one `DEFECT_LINEAGE` model. Add one focused validator for D0 repair and D1 routing receipts; keep D2/D3 unchanged except existing Candidate invalidation and evidence consumption.

**Tech Stack:** Markdown, YAML, JSON, Python 3.12+, pytest, PyYAML.
