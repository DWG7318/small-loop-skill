## 验证方式

- 比较改写前后相同角色/情境的实际必读文件与 UTF-8字节/字符，不用整库行数或搬参考假称减负。
- 保留既有行为测试。文案测试改为检查唯一权威位置及可达规则，不要求一段重复文字同时出现在所有 Skill。
- 情境包括正常链、首FAIL/第二FAIL、INCOMPLETE、已保存未投递、OW UNKNOWN/报告继续/多Run、暂停半提交恢复、D2及归档。
- 独立 Agent 只取角色当次实际所需指引作决策，不预喂正确答案；不能把桌面演练声称生产多 Agent 验收。
- 已验445修复和权限/证据/事务行为不因精简退回。不得增加统一时间、行数、Token、材料读取或CELL容量硬门槛。
