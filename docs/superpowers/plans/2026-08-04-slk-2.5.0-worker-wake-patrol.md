# SLK 2.5.0 Worker Wake, Run Patrol, and Layered Progress Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:executing-plans` inline in this task. Subagents, delegated agents,
> forked tasks, and replacement Codex tasks are forbidden.

**Goal:** Ship SLK 2.5.0 with a machine-enforced Worker wake ladder, bounded wait
policy, unique non-authoritative Run Patrol, precise subagent definition, and
receipt-derived layered progress.

**Architecture:** Extend the existing kernel with compact authority invariants and
add one closed runtime-control schema plus one pure YAML validator. The host performs
thread/heartbeat operations; SLK validates immutable preflight, wake, pending,
patrol, progress, and simulation records. Root and install trees remain byte-for-byte
mirrors.

**Tech Stack:** Python 3.12+, PyYAML, JSON, pytest, Git, GitHub Actions.
