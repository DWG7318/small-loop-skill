# SLK 4.3.3 OCRV Preflight Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Subagents are explicitly forbidden for this upgrade, so all steps execute inline in the existing SLK owner thread.

**Goal:** Ship SLK 4.3.3 with executable three-Agent readiness, Owner-confirmed optional features and real capacity-bounded OCRV D1 segmentation.

**Architecture:** Add one closed dependency-free readiness CLI and replace descriptive OCRV segmentation with an adapter preview contract that measures exact backgrounds and real selected paths. Reuse the existing transport, OCRV process, Skill collection, package builder and transactional installers; keep semantic decisions in agents and deterministic facts in code.

**Tech Stack:** Python 3.10+, pytest, JSON Schema, OCRV 1.12.7 CLI, PowerShell transactional installers, existing Rust state/BI validation.
