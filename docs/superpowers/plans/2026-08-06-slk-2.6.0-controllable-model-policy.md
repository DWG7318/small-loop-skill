# SLK 2.6.0 Controllable Model Policy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Owner forbids subagents for this version.

**Goal:** Add fail-closed, versioned model selection and switch evidence to SLK while preserving its existing topology and execution flow.

**Architecture:** Add one `MODEL_BINDING_TRACE` runtime record and validator. Existing runtime contract, dispatch index, Patrol receipt, and technical receipt templates reference the trace/bindings; policy remains evidence governance rather than a router or runtime service.

**Tech Stack:** Markdown/YAML/JSON Schema, Python 3 validator, pytest, SHA-256 Manifest.
