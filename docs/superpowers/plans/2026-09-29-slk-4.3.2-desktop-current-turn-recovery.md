# SLK 4.3.2 Desktop Current-Turn Recovery Implementation Plan

> **Execution:** Implement inline in the dedicated SLK owner thread. Subagents and new roles are not used.

**Goal:** Recover one exact Checker-to-Supervisor handoff when Codex Desktop already owns the registered Supervisor writer, without forging native start or changing Run state.

**Architecture:** Add a two-phase, evidence-bound Desktop bridge to the existing Python transport. The Desktop host performs native read/send/read; the transport validates a closed host receipt and writes immutable recovery/start evidence. Bound JSON-RPC diagnostics prevent giant failure transcripts.

**Tech Stack:** Python 3, pytest, Rust state core compatibility tests, Codex Desktop app tools, existing deterministic package/installer scripts.
