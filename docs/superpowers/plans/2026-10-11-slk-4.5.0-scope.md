# SLK 4.5.0 范围记录

日期：2026-10-11（北京时间）。状态：Owner 已确定版本边界，尚未施工；不是实现或验收完成声明。

## 前置版本

4.4.5 完成已有必要修复并验收后关闭；4.5.0 以修复后的版本为基线，不承接未完成维修任务。本记录不改源码版本、真实 Run、安装环境或发布状态。

## 已确认范围

- 轻量准备：每次只确认完整 SLK/Skill、DSH/OCRV 等必要组件、成员真实身份与端点、BI 可用及共享 Temporal/本 Run 工作流就绪；不要求每个 Run 重跑完整流程验收。
- 时间目标：基本检查不超过 10 分钟，缺项配置再不超过 10 分钟，全部准备不超过 20 分钟。外部故障明确报告，不能假通过或无限维持“准备中”。
- 成品交付：开发/发布阶段准备并验证 BI、状态/查询工具、传输包、DSH/OCRV 依赖与适配器、Temporal 配套依赖/模板、探针和默认配置；使用者调用现有安装入口，不现场编译或反复组装。
- 一键部署：安装包已下载、凭据可用的正常目标环境，一分钟内完成正常部署并打开 BI。下载等外部耗时单独如实显示，缺失成品不自动退回源码构建。
- 本机与 Run 变量仍现场绑定：凭据、设备路径、成员 Session/端点、Run 身份及 Owner 选择的参数不预造、不锁死，也不随公共包传播。
- 主/子 Skill 瘦身：优先整理现有集合；主 Skill 保留总则、角色边界与情境导航，子 Skill 各管明确情境，技术细节按需读取，同一规则保留一个权威出处。
- 去重去繁不偷改语义：保留既定角色、通讯责任、D0/D1/D2、TOKEN、权限与真实证据边界；轻量准备属于 Owner 已批准的调整，其他整理逐条核对旧规则归属，不以删行数或单文件硬上限作为完成标准。

## 不做

不另造管理底座、不无限新增子 Skill、不要求成员加载全套文档、不复制不可迁移的虚拟环境、不新增重预检。不安装 Docker；不把此范围记录视为恢复施工、部署或发布完成。
