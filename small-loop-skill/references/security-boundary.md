# Security Boundary

SLK performs Run Contract-local safety checks. LCCoding owns centralized
project-wide vulnerability discovery and closure.

Known Critical/High vulnerability, authentication or authorization bypass,
privilege escalation, credential leakage, cross-tenant leakage, destructive risk,
or a failed Run security requirement blocks D3 and Owner Acceptance. Remediation
invalidates affected receipts and product-visible changes invalidate prior Owner
Acceptance.
