# LCCoding Interface

Input is a frozen `RUN_CONTRACT` carrying authoritative product, integration,
acceptance, autonomy, candidate, and local security bindings. SLK never invents or
changes those meanings silently.

Output is `SLK_RUN_RECEIPT` plus explicit `LOOP_OWNER_ACCEPTED`. LCCoding aggregates
Required Runs, performs centralized security closure, obtains any Post-Security
Owner Acceptance, and owns delivery.
