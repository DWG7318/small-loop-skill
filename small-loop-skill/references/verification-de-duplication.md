# Verification De-duplication

D0 checks local implementation. D1 checks the frozen CELL Contract. D2 checks GO
composition. D3 checks Run composition. Higher layers consume immutable lower-layer
receipts and add only their own boundary claims and risks.

Repeat a check only for material candidate/environment change, expired or
contradictory evidence, composition effect, expanded regression, or a specific new
risk. Record source layer, reason, scope difference, and result.
